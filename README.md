O projeto do Snake Game é fácil de jogar. Clique a barra de espaço para começar e use WASD ou as teclas de setas para se movimentar, é game over somente se você bater em uma das paredes.
Diferente do original, essa versão inclui um tipo de comida especial que vale mais pontos e uma paleta de cores única.
Créditos: desenvolvido por Isabela Vargas.
